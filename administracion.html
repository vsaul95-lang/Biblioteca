Usuarios y permisos

Esta sección prepara la estructura de permisos que posteriormente permitirá controlar qué funciones puede utilizar cada persona.

Usuario

Perfil pensado para las personas que realizarán las tareas cotidianas de la biblioteca.

  • Registrar libros
  • Registrar préstamos
  • Registrar devoluciones
  • Buscar información
  • Consultar información necesaria para su trabajo

Administrador

Perfil con acceso completo para administrar la información y el funcionamiento del sistema.

  • Acceso a todos los módulos
  • Importar información desde Excel
  • Administrar familias y afiliados
  • Administrar libros y colaboradores
  • Consultar y descargar reportes
  • Realizar respaldos y restauraciones
  • Administrar usuarios y permisos
Estado: La administración de usuarios todavía no está activada. La estructura visual está preparada para conectarla posteriormente con Supabase Auth y los roles del sistema.
