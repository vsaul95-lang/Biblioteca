Administración de datos

Utiliza estas opciones para guardar una copia completa de la información o restaurar los datos desde un respaldo anterior.

Mantenimiento de préstamos

Elimina únicamente los registros de préstamos. Los libros, afiliados y colaboradores permanecerán en la base de datos.

Reinicio completo de la biblioteca

Esta opción elimina todos los datos actuales para permitir comenzar nuevamente desde cero después de una presentación o prueba.

Información del respaldo

El respaldo incluye:
Libros, afiliados, colaboradores y préstamos completos, incluyendo registros activos, inactivos, dados de baja y el historial de préstamos.

Importante:
La opción "Limpiar todo" elimina los datos almacenados actualmente en las cuatro tablas principales. Esta acción no elimina las tablas ni la estructura del sistema.

Se recomienda crear un respaldo antes de utilizar las opciones de limpieza.
